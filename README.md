# taskflow1
O TaskFlow é um sistema web de gerenciamento de tarefas proposto para a empresa fictícia TechFlow Solutions, que atende uma startup de logística. O sistema permite cadastrar, consultar, editar e excluir tarefas, definir prioridades e acompanhar o status de cada atividade. O escopo inicial contempla o CRUD e um painel com indicadores básicos.
